# نظام تتبع خروج الطلاب

نظام بـ PHP و MySQL لتسجيل استئذان الطلاب بالخروج من الصف (حمام/ممرضة/إدارة) وربط المتابعة بين المعلم والمرشد الطلابي ووكيل شؤون الطلاب لحظياً.

## التركيب على السيرفر

1. أنشئ قاعدة بيانات MySQL/MariaDB واستورد إليها ملف `schema.sql`.
2. انسخ `config/config.sample.php` إلى `config/config.php` وعدّل بيانات الاتصال (host/اسم القاعدة/المستخدم/كلمة المرور).
3. ارفع المجلد كاملاً إلى مجلد الاستضافة (يدعم Apache + PHP 7.4 أو أعلى).
4. سجّل الدخول بالحساب الافتراضي:
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`
5. **غيّر كلمة مرور المدير فوراً** من صفحة "الحسابات" بعد أول دخول.

## إدخال البيانات (من لوحة التحكم بعد تسجيل الدخول كمدير)

1. **المراحل والشعب**: المراحل (أول/ثاني/ثالث ثانوي) موجودة مسبقاً، أضف الشعب لكل مرحلة.
2. **الطلاب**: أضف طلاب كل شعبة.
3. **الحسابات**: أنشئ حساب لكل معلم (مع تحديد الشعب التي يدرّسها) وحساب مرشد لكل مرحلة وحساب وكيل شؤون الطلاب.

## الأدوار

- **معلم**: يسجل خروج وعودة طلاب شعبه فقط.
- **مرشد طلابي**: يشاهد لحظياً كل الطلاب الخارجين في مرحلته، مع تنبيه للمتأخرين عن المدة المسموحة (10 دقائق)، ويمكنه تسجيل عودة الطالب.
- **وكيل شؤون الطلاب**: يشاهد كل المراحل مجمّعة مع تنبيهات التأخر، ويمكنه التصفية والتصدير.
- **مدير النظام**: يدير المراحل/الشعب/الطلاب/الحسابات من لوحة التحكم.

## ملاحظات أمنية

- لا ترفع ملف `config/config.php` إلى أي مكان عام (مستثنى من Git تلقائياً).
- يُفضّل تفعيل HTTPS على السيرفر لأن النظام يستخدم تسجيل دخول بكلمة مرور.
